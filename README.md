# Bastotan
Bastotan fil ilmi wal jism

I wanted to make an integrated app based on the quranic verse: bastotan fil ilmi wal jism, which means excel in knowledge and in physical ability.
The app would feature an integraed daily tracker for physical exercise, language learning, and spiritual routine. 
Similar to a mix of strava, dulingo, and quran app and that will be in one app.
The app also feature means to invite or reminds friends that has not done their routine track. 
My goal was to improve muslim community in all aspects of life, using the FOMO trends among the youth.
The app will have feature such as:
1. Quran recitation tracker
2. Exercise tracker (gps)
3. learn arab with x language (user can choose) based on the words in quran.
4. dzikrullah or tafaqqur, which the user will choose a timer and other app would be disasbled for that time so the user can focus on remembering Allah, gratitude, etc
5. infaq
6. remind others (nudge/invite)
7. share to social media. the daily record will be compiled to a matrix or graphs and can be shared. it is permissible to compete in kindness (fastabiqul khairat)
